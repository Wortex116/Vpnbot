# MULTI-SNOS v8.0

Автоматизированный снос Telegram аккаунтов, каналов и чатов через мульти-сессионную атаку.

## Возможности

- 5 аккаунтов × 11 сессий = 55 одновременных жалоб
- 1650 жалоб в минуту
- Бан цели за 2-5 минут
- Вероятность: 95-99%

## Установка

```bash
git clone <url_репозитория>
cd snos-tg
pip install -r requirements.txt
